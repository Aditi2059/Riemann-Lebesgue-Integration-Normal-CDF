Riemann & Lebesgue Integration + Normal CDF

A numerical study of domain vs. range partitioning, and efficient computation of the standard normal cumulative distribution function.

Ex. 1   Riemann and Lebesgue Integration

We compare two numerical integration strategies. The Riemann approach partitions the domain into subintervals and samples the function. The Lebesgue approach partitions the range into measurable bins and sums over the measure of their preimages.

Riemann (midpoint) rule

∫ab f(x) dx  ≈  Σi=1n f(xi*) · Δx,   xi* = a + (i − ½)Δx

Lebesgue-style sum

∫ab f dμ  ≈  Σj=1m yj* · μ( f−1([yj, yj+1)) )

Code (core logic)

// Riemann midpoint
function riemann(f, a, b, n) {
  let s = 0, dx = (b - a) / n;
  for (let i = 0; i < n; i++) s += f(a + (i + 0.5) * dx);
  return s * dx;
}

// Lebesgue-style (fine grid → bin range → measure × center)
function lebesgue(f, a, b, m, N = 200000) {
  const dx = (b - a) / N, y = new Array(N);
  let ymin = Infinity, ymax = -Infinity;
  for (let i = 0; i < N; i++) {
    const v = f(a + i * dx);
    y[i] = v; if (v < ymin) ymin = v; if (v > ymax) ymax = v;
  }
  if (ymax === ymin) return ymin * (b - a);
  const width = (ymax - ymin) / m, cnt = new Array(m).fill(0);
  for (const v of y) {
    let k = Math.floor((v - ymin) / width);
    if (k < 0) k = 0; if (k >= m) k = m - 1;
    cnt[k]++;
  }
  let s = 0;
  for (let j = 0; j < m; j++)
    s += (ymin + (j + 0.5) * width) * cnt[j] * dx;
  return s;
}

Discussion

  • Smooth functions (sin, x², |x−½|, sinc): the midpoint Riemann sum converges at O(n⁻²), and matches the Lebesgue result for sufficiently fine grids.
  • Step functions: both methods are essentially exact — the midpoint samples land inside each constant piece.
  • Singular integrands (1/√x): both methods lose accuracy near x = 0; the Riemann sum converges slowly.
  • Dirichlet function: the Riemann sum does not converge (the value depends on the sampled points). The Lebesgue integral is 0 since μ(ℚ) = 0.
  • Thomae's function: both converge to 0, because the discontinuities form a measure-zero set (Lebesgue's criterion).

For Riemann-integrable functions both schemes converge to the same value. For pathological functions, the Lebesgue approach still gives a well-defined answer — that's the conceptual payoff.

Ex. 2 : Numerical Computation of the Normal CDF

The standard normal pdf is φ(x) = (1/√(2π)) e−x²/2 and the CDF is Φ(x) = ∫−∞x φ(t) dt.

Why no elementary antiderivative?

By Liouville's theorem, if ∫f(x)eg(x)dx is elementary (with f, g rational), there must exist a rational R with R′ + Rg′ = f. Taking g(x) = −x²/2 and f = 1 forces R′ − xR = 1, which has no rational solution. Hence Φ has no elementary closed form.

The error function

erf(z) = (2/√π) ∫0z e−t² dt Φ(x) = ½ [ 1 + erf(x/√2) ]

This is an exact analytical representation, but erf is itself a special function, so numerics are still required in practice.

Three numerical methods

// 1> Simpson's rule on the pdf
function phiSimpson(x, n = 2000) {
  if (n % 2) n++;
  const a = Math.min(-10, x - 8), b = x;
  if (b - a < 1e-12) return 0;
  const h = (b - a) / n;
  const f = t => Math.exp(-t*t/2) / Math.sqrt(2 * Math.PI);
  let S = f(a) + f(b);
  for (let i = 1; i = n; i++) S += (i % 2 ? 4 : 2) * f(a + i * h);
  return S * h / 3;
}

function erfSeries(z, terms = 40) {
  let s = 0;
  for (let k = 0; k : terms; k++) {
    let fact = 1; for (let j = 1; j = k; j++) fact *= j;
    s += (-1)**k * z**(2*k + 1) / (fact * (2*k + 1));
  }
  return 2 / Math.sqrt(Math.PI) * s;
}

function phiAS(x) {
  const t = 1 / (1 + 0.2316419 * Math.abs(x));
  const d = 0.3989423 * Math.exp(-x * x / 2);
  const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.781478 +
            t * (-1.821256 + t * 1.330274))));
  return x : 0 ? 1 - p : p;
}

Efficiency accuracy

  • Simpson: accurate to ~1e-8 with n = 2000, but O(n) per evaluation — wasteful if many points are needed.
  • Power series: excellent for |x| ≲ 2, but suffers from cancellation and overflow in the tails.
  • AS rational approximation: O(1) per call, ~1e-7 accuracy — ideal for tables and vectorized code.
  • In practice, a compiled erf (or a vectorized series) is the best balance of speed and precision.

Special functions give exact analytical representations, but evaluating them numerically is unavoidable. The normal CDF is therefore computed via series, continued fractions, or rational approximations.
